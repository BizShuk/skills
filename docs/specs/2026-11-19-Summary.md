## 已淘汰 (Deprecated)

無整列淘汰。下列`設計細節`已被後續變更取代，以程式碼現況為準：

- 2026-07-04 的 package 佈局（`cmd/skills/main.go`、`svc/source`、`svc/manifest`、`svc/install`）已重整為根目錄 `main.go` + `cmd/`、`svc/fetch`、`svc/plugin`、`svc/agent`；預設 scope 由 project 層改為 global（`--global` 預設為 `true`）。
- 2026-07-11 建立 `CLAUDE.md` 並以 `AGENTS.md` symlink 指向它的做法，已改為 `AGENTS.md` 實體檔、移除 `CLAUDE.md`。
- 2026-07-12 與 2026-07-13 把 `.claude/skills`、`.agents/skills`、`.claude/agents`、`.agents/agents` 視為來源的設計已收回：來源掃描與 fallback 只看 repo 根目錄的 `skills/` 與 `agents/`，安裝目的地不再被當成來源。
- 2026-07-12 計畫中的 `update.DropNames` 實作為 `update.DropNamesByScope`。
- 2026-07-18 `list-agent-sessions` 以解析 transcript 判定 cwd 的 discovery，已由 metadata-only list 取代；Antigravity、Hermes、OpenCode、Pi 在具備 project-scoped path 或 metadata index 前不出現在列表。
- 2026-07-24 計畫中 `svc/token` 自行實作的重試政策，已收斂到 `github.com/bizshuk/gosdk/http` 的共用 5 次指數退避。
